# NXT Fit Out Technical Service: демо-сайт

Чистые HTML + CSS + JS, без сборки. Открой `index.html` двойным кликом: сайт работает прямо в браузере.

## Структура
```
index.html      главная: шапка, два 3D-барабана, центр, подвал
styles.css      все стили (цвета и размеры в :root в начале файла)
script.js       барабаны, переключение панелей, перевод
changelog.js    история обновлений и номер версии
i18n.js         настройки (год основания, версия) и ВСЕ тексты EN / RU / AR
projects.js     данные проектов (массив объектов)
privacy.html    политика конфиденциальности (заглушка)
terms.html      условия предоставления услуг (заглушка)
assets/images   фото проектов
assets/logo     логотип: nxt-logo-black.svg и nxt-logo-white.svg
```

## Как добавить проект
1. Положи фото в `assets/images/`.
2. В `projects.js` скопируй любой объект и поменяй поля:
```js
{
  id: 121,
  side: "left",                      // "left" или "right": на каком барабане
  title: { en: "Villa Azure", ru: "Вилла Azure", ar: "فيلا أزور" }, // или просто "Villa Azure"
  location: { en: "Palm Jumeirah", ru: "Пальм-Джумейра", ar: "نخلة جميرا" },
  workType: "marble",                // fitout | renovation | marble | tile | parquet | metal | glass | wood
  year: 2025,
  area: 640,                         // м²
  description: { en: "...", ru: "...", ar: "..." },
  images: ["assets/images/azure-1.jpg", "assets/images/azure-2.jpg"] // первое фото идёт на карточку
}
```
Код трогать не нужно. 120 демо-проектов можно просто удалить из массива.

## Окно проекта
Кнопка «Подробнее о проекте» (или клик по фото в центре) открывает окно поверх сайта: все фото,
описание, состав работ, кнопка WhatsApp и переход к следующему проекту. Отдельной страницы нет.
У каждого проекта своя ссылка: `index.html#project-12` откроет сразу проект с id 12.

Необязательные поля проекта для окна (если их нет, блок просто не показывается; для состава работ берётся типовой список):
```js
details:  { en: "Full story…", ru: "Полный рассказ…", ar: "…" },   // абзацы через пустую строку
scope:    [{ en: "Marble polishing", ru: "Полировка мрамора" }, …], // состав работ (иначе типовой список по workType)
duration: { en: "6 weeks", ru: "6 недель", ar: "6 أسابيع" },
client:   "Private client"
```

## Как поменять тексты и языки
Все тексты лежат в `i18n.js` по ключам (`welcome.title`, `footer.privacy` и т.д.), отдельно для `en`, `ru`, `ar`.
В HTML элемент связан с ключом атрибутом `data-i18n="ключ"`. Год основания и номер версии задаются в `NXT_SITE` в начале `i18n.js`.
Чтобы добавить язык: добавь новый блок в `NXT_I18N`, кнопку в `.lang` в HTML и код языка в массив `LANGS` в `script.js`.
Арабский автоматически переключает страницу в режим RTL.

## Версия и история обновлений
Каждая правка сайта = новая строка в конце `changelog.js`:
```js
{ v: "0.10", date: "2026-11-25", text: { en: "...", ru: "...", ar: "..." } }
```
Номер версии в подвале (`v0.10`, потом `v0.11` и т.д.) берётся оттуда автоматически.
По клику на версию в подвале открывается список всех обновлений.

## Как поменять логотип
Замени `assets/logo/nxt-logo-black.svg` (шапка) и `assets/logo/nxt-logo-white.svg` (подвал) своими файлами с теми же именами. Подойдёт и PNG, тогда поправь путь в `index.html`, `privacy.html`, `terms.html`.

## Контакты
Телефон и ссылки WhatsApp / Instagram прописаны в `index.html` (шапка и подвал). Instagram сейчас ведёт на `#`.

## Управление
- Колесо мыши или тачпад над барабаном: вращение с инерцией и доводкой до ближайшей карточки.
- Перетаскивание мышью / свайп, клик по карточке, стрелки на клавиатуре.
- Колесо над центром: сначала возвращает блок о компании, дальше обычная прокрутка к подвалу.
- На телефоне (до 820 px) барабаны становятся горизонтальными, сверху; информация о проекте под ними.

## Публикация на GitHub Pages
1. Залей файлы в репозиторий (в корень ветки).
2. Settings → Pages → Source: «Deploy from a branch», выбери ветку и папку `/ (root)`.
3. Через минуту сайт будет на `https://<user>.github.io/<repo>/`.
